# VYNKA — Landing Page

Landing page tahap pertama untuk brand VYNKA dengan desain dark-tech responsif.

## Identitas GitHub yang digunakan

- Username GitHub: `vynka-id`
- Repository GitHub Pages: `vynka-id.github.io`
- Alamat website utama: `https://vynka-id.github.io/`

> Catatan: GitHub Pages tidak bisa memberikan alamat `vynka.github.io` jika akun/organisasi GitHub yang memiliki nama `vynka` tidak tersedia. Dengan username `vynka-id`, alamat bawaan yang benar adalah `vynka-id.github.io`.

## Deploy ke GitHub Pages

1. Login ke GitHub dengan akun `vynka-id`.
2. Buat repository baru bernama persis **`vynka-id.github.io`**.
3. Ekstrak ZIP ini.
4. Upload seluruh isi folder ke **root** repository, sehingga `index.html`, `style.css`, dan `script.js` berada langsung di root.
5. Buka **Settings → Pages**.
6. Pada **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch `main`, folder `/ (root)`, lalu klik **Save**.
8. Tunggu deployment selesai, lalu buka `https://vynka-id.github.io/`.

## Catatan penting

- Jangan mengunggah folder `VYNKA-Landing-Page` sebagai satu folder di dalam repository. Upload file di dalamnya ke root repository.
- Ini baru landing page informasi VYNKA. Belum ada pendaftaran, login, dashboard, database, atau pembuatan profil multiuser.
- Tahap multiuser memerlukan backend/database (misalnya Supabase) dan pengaturan routing profil.
